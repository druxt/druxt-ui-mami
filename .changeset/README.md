# Changesets

A change a site would notice records a changeset with it: `npm run changeset`,
pick the bump, and write the line that goes in the changelog.

The first release will be 0.1.0 as the package stands today, so nothing
before that release needs a changeset: it is all part of 0.1.0.
From the first release on, every change a site would notice carries one. See
[CONTRIBUTING.md](../CONTRIBUTING.md#changesets).
